# Demonstration asset provenance

All 19 SVGs are original hand-authored vector illustrations and derivatives created for the owner-requested local UX prototype on 2026-10-26. No AI image provider, third-party photography, private account assets, W7 references, model photographs or verified product variants were used.

ZOE is an illustrative luxury-product study. NOVA ARENA, NORTHLINE, FORME and AZURE STAYS are fictional demonstration systems. Product-isolated and background/foreground files derive only from these original vector fixtures; they do not demonstrate photograph segmentation. Fashion contains garment illustrations, not a human model.

Brand names are editable text, not authenticated logos or wordmarks. Palette/type choices are illustrative, using the existing local font catalog. Collection repeats the same red product; it does not establish inventory. Other taxonomy categories use explicitly generic artwork.

ASSET-MANIFEST.json records every SVG and SHA256. taxonomy.snapshot.json records public source taxonomy provenance. Existing W0A sample assets are untouched. These assets are suitable for product interaction review, not professional photographic-quality acceptance.
